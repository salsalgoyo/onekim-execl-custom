1. 엑셀 파일 업로드 및 자동 병합

💡 이럴 때 사용하세요: 흩어져 있는 지점별 매출 자료, 월별 회원 목록 등 동일한 형식의 여러 엑셀 파일을 하나로 합치고 싶을 때 유용합니다.
  • 메인 화면의 파란색 점선 상자 영역에 합치고 싶은 엑셀 파일(`.xlsx`, `.xls`, `.csv`)들을 마우스로 끌어다 놓거나(드래그 앤 드롭) 버튼을 클릭하여 다중 선택합니다.
  • 여러 파일을 올릴 경우, 가장 첫 번째 파일의 첫 시트 헤더를 기준으로 열 이름이 자동 매핑되어 병합됩니다.
  • 병합이 완료되면 왼쪽 상단 목록에 파일들이 나타나며, 파일명 우측의 드롭다운을 통해 불러올 시트를 개별적으로 변경할 수 있습니다.
  • 여러 파일 병합 시, 결과 데이터 맨 왼쪽에 자동으로 `[원본 파일명]` 열이 삽입되어 각 행이 어떤 파일에서 왔는지 구별이 용이해집니다.

2. 필요한 열 선택 및 순서 변경

💡 이럴 때 사용하세요: 원본 엑셀에 쓸데없이 불필요한 열이 너무 많을 때, 원하는 항목만 고르고 추출하거나 출력 순서를 보기 좋게 바꾸고 싶을 때 사용합니다.
  • 왼쪽 설정창의 **'2. 열 선택 및 순서 변경'** 목록에서 엑셀의 열 이름들을 확인할 수 있습니다.
  • 다운로드할 엑셀에 포함시킬 열은 **체크박스에 체크**하고, 불필요한 항목은 체크 해제합니다.
  • 열 항목의 맨 왼쪽 **`≡` 핸들**을 누른 상태로 위아래로 끌어서 움직이면 미리보기 테이블의 열 정렬 순서가 실시간으로 바뀝니다. (맨 위의 열이 엑셀 파일의 가장 왼쪽 열이 됩니다.)

3. 스마트 조건 필터 (전체검색 / 📌 행 고정)

💡 이럴 때 사용하세요: 수많은 행 중에서 특정 조건을 가진 행들만 추려내고 싶거나, 검색 결과와 무관하게 엑셀의 특정 행(예: 머리글, 합계행 등)은 무조건 화면에 항상 띄우고 싶을 때 씁니다.
  • **`[+ 조건 추가]`** 버튼을 눌러 필터를 무한히 생성할 수 있습니다. 다중 필터 적용 시 모든 조건을 동시에 충족하는 행만 보입니다.
  • 전체 열 검색: 열 선택 드롭다운에서 **`[전체 열]`**을 선택하고 검색어를 입력하면, 특정 열이 아닌 모든 열 중에서 검색어가 1개라도 포함된 행을 똑똑하게 추려냅니다.
  • 행 고정(📌) 기능: 미리보기 목록 가장 왼쪽에 있는 📌 체크박스를 활성화한 행은 필터 검색 조건을 어떻게 입력하든 상관없이 무조건 결과 화면에 고정되어 항상 유지됩니다. (선택 해제 시 다시 필터가 적용됩니다.)

4. 데이터 정렬 및 중복 제거

💡 이럴 때 사용하세요: 가나다순 혹은 숫자 크기순으로 깔끔하게 행을 정렬하거나, 이메일이나 연락처 등 동일한 사람의 정보가 겹쳐져 있는 경우 하나만 남기고 전부 지우고 싶을 때 사용합니다.
  • 중복 데이터 제거: **`[확인(적용)]`** 버튼을 누르면 화면에 선택된 열들의 조합을 기준으로 중복된 값을 가진 모든 행을 제거하고 유일한 1개의 행만 남깁니다. 취소하고 싶다면 **`[적용 취소]`**를 클릭합니다.
  • 데이터 정렬: 정렬할 대상 열을 지정하고 **오름차순(가나다, 숫자 작은 순)** 또는 **내림차순(하파타, 숫자 큰 순)**을 고르면 실시간으로 데이터 행 위치가 정렬됩니다.

5. 지정 열 서식 통일 / 문자 추가 및 삭제

💡 이럴 때 사용하세요: 서로 다른 파일에서 가져오다 보니 날짜 입력 형식이 뒤죽박죽일 때, 숫자에 천 단위 쉼표(,)를 한 번에 넣고 싶을 때, 혹은 일괄적으로 특정 단어를 앞뒤에 붙이거나 지우고 싶을 때 사용합니다.
  • **`[+ 서식/문자 규칙 추가]`**를 눌러 원하는 규칙을 추가합니다. 여러 개의 규칙을 동시에 적용할 수 있습니다.
  • 제공되는 대표 서식 처리 기능:
    • **공백 제거**: 셀 안의 앞뒤 불필요한 무의미한 띄어쓰기 공백을 전부 잘라내 줍니다.
    • **날짜 통일**: `2026/05/23` 또는 `2026.5.23` 등의 다른 포맷을 모두 깔끔한 표준 규격 **`2026-05-23`** 형식으로 강제 변환합니다.
    • **숫자 쉼표 추가**: 숫자로 이루어진 데이터 열을 천 단위 구분 기호가 있는 통화 표시 형식(`1234567` ➔ **`1,234,567`**)으로 바꿉니다.
    • **앞/뒤 글자 추가**: 열의 모든 값 앞 또는 뒤에 지정한 문자를 붙입니다. (예: 주소 열 뒤에 **` (본점)`** 추가)
    • **특정 단어 삭제**: 셀 값 안에 포함된 단어를 찾아내어 제거합니다.

6. 통계 및 요약 계산 (세로/가로 요약)

💡 이럴 때 사용하세요: 엑셀의 수식 입력 필요 없이 특정 열들의 가로 합계/평균을 새로운 열로 만들어 추가하거나, 표 맨 아랫줄에 특정 데이터의 최종 통계치(합계, 평균, 개수)를 도출하고 싶을 때 사용합니다.
  • 세로/열 하단 요약 (표 맨 아랫줄 추가):
    • 지정한 특정 열의 아랫줄에 **[총 합계]**, **[평 균]**을 소수점 2째 자리까지 연산하여 붙이거나, 데이터 행이 총 몇 개인지 **[데이터 건수]**를 집계합니다.
    • '데이터 개수 세기'의 경우, 조건값 입력칸에 단어(예: `네모`)를 적으면 그 열에 섞여 있는 여러 항목 중 오직 '네모'인 데이터의 개수만 쏙 골라서 집계해 줍니다.
  • 가로/행 우측 요약 (표 맨 오른쪽 열 추가):
    • **`[+ 가로 통계 열 추가]`**를 누르고 원하는 열 이름(예: `총점`)을 적습니다.
    • 계산 타입(합계/평균)을 선택한 뒤, 계산에 반영할 행의 체크박스 열들을 골라 체크해주면 실시간으로 오른쪽에 해당 수식이 대입된 가로 합산 통계 열이 새로 추가됩니다.

7. 고급 초보자를 위한 마우스 편집 & 단축키

💡 이럴 때 사용하세요: 마우스 클릭 노가다를 줄이고 엑셀 그리드(격자판)처럼 화면 안의 표를 가장 빠르고 유연하게 다루고 싶을 때 활용하는 고급 기능입니다.
  • 셀 다중 범위 지정: 임의의 셀을 클릭한 채 마우스를 대각선으로 드래그하면 엑셀처럼 여러 셀이 하늘색 영역으로 다중 선택됩니다.
  • 엑셀 데이터 붙여넣기 (Ctrl + V): 일반 엑셀 파일에서 다중 셀을 복사(`Ctrl + C`)한 후, 본 프로그램의 미리보기 셀을 선택하고 `Ctrl + V`를 누르면 복사한 표의 모양(행/열 격자) 그대로 한꺼번에 정렬되어 붙여넣어집니다.
  • 500행 그리드 및 빈 칸 입력: 데이터 개수가 부족하더라도 항상 500개 행의 격자판이 노출됩니다. **이 빈 공간에 붙여넣거나(Ctrl+V) 셀을 더블클릭하여 직접 글씨를 쓰면**, 자동으로 빈 행이 정식 원본 데이터 행으로 등록 및 승격됩니다.
  • 선택 행 일괄 삭제: 삭제하고 싶은 행의 📌 체크박스를 선택하거나 마우스로 삭제하려는 행들의 셀을 쭉 드래그한 뒤, 우측 상단의 **`[선택 행 삭제]`** 버튼을 누르면 해당 행들이 목록에서 사라집니다. (행 우측의 `×` 버튼을 누르면 해당 1개 행만 신속하게 즉시 지워집니다.)
  • 작업 되돌리기 (Ctrl + Z): 데이터 편집이나 삭제를 잘못했을 때, 상단 **`[실행 취소(되돌리기)]`** 버튼을 누르거나 키보드 단축키 **`Ctrl + Z`**를 누르면 완벽하게 바로 전 단계로 회귀합니다. (최대 30단계까지 복구 가능)
